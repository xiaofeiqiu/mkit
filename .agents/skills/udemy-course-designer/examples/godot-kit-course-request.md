# Example Skill Invocation

```text
$udemy-course-designer

You are a professional Udemy instructor and course designer.
Read the `new-kit` branch of this repository.
Design a commercially viable Udemy course from this project.

My goal is to sell this course on Udemy.
Do not only teach how to implement the repo.
After each major system, students should use it in a real demo scene.

Please include:
- course positioning
- target students
- final project
- first-course scope
- what to cut
- full curriculum
- reusable lesson structure
- detailed first lesson
- first 5-lesson MVP
- Udemy landing page copy
```
```

## Expected Style

The answer should not be a plain file-by-file walkthrough.

It should feel like a productized course plan:

```text
We are not selling "MKit Tutorial".
We are selling "Godot 4 Modular RPG Framework".
```
