# Market Positioning Checklist

Use this checklist when turning a project into a Udemy course.

## Title Formula

```text
Technology + Outcome + Project Type
```

Examples:

```text
Godot 4 Modular RPG Framework: Build a Reusable 2D Roguelike Game Kit
FastAPI Microservices: Build, Test, and Deploy a Production Backend
React SaaS Dashboard: Build a Production-Ready Admin App
Python ML Feature Store: Build Training Data Pipelines from Scratch
```

## Strong Course Promise

A strong promise answers:

```text
What will the student become able to build?
Why is this useful beyond the course?
What final artifact will they have?
```

## Student Pain

Identify the pain clearly:

```text
My Godot prototype code becomes messy.
I can build a demo but not a reusable framework.
I know FastAPI basics but not production structure.
I know React components but not a real app architecture.
I know Python but not ML data pipelines.
```

## Transformation

Write the transformation like:

```text
Before:
The student can build small prototypes but starts from zero each time.

After:
The student can build a reusable framework and apply it to future games.
```

## Commercial Scope

The first course should be:

```text
Specific enough to sell.
Small enough to finish.
Deep enough to feel valuable.
Visual enough to market.
Reusable enough to justify purchase.
```

## Cut List Rule

Always include a cut list.

A course that teaches everything usually teaches nothing well.
