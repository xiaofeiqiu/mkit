**PROJECT WHISPERING FOREST**

游戏设计文档 / Game Design Document

v0.14 / Story v3.1 · 2026-09-06 · Solo Developer / Godot

人物美术按用户新增参考采用简洁立体体块；玩家、可移动NPC与怪物制作八方向，行走需有抬脚/落脚、膝盖弯曲、摆臂与重心，待机有呼吸/眨眼。当前v0.4样板已用同一关节模型烘焙玩家/梅尔/哥布林的八向动态，其他专用动作与全场景笔触继续迭代，详见Design Full第7节。

当前剧情已改为Story v3.1：召唤主城/城外副本/地下灵堂→海底→雪山神庙→千年前古城与归来→巴别塔/天空四塔→神座阻止军神为爱开启时空之门与无限轮回；含中英NPC对白，详见第13节与Design Full。系统规则摘要：每职业4个普通技能+1个终极技能；法师普通技能对应火/风/地/水，终极为结印召唤火陨石；打关卡积攒怒气，怒气满后手动释放终极。具体数值、技能ID与关联装备见 [Design Full.md](<Design Full.md>) 第3节。Boss HP已改为指数成长，并同步设计玩家输出与大数字反馈，见完整设计第2.3.1节。远征强化采用通用加成与白/金/紫三级，具体卡表见完整设计第3.5节。猎人与矿工改为可升级的在线/离线自动采集，含专精、多线路与制作目标补货，见完整设计第6.3节。装备穿戴按属性要求、制作只需材料且不受章节限制，成品有随机属性及普通/少见/稀有/传承四档稀有度，见完整设计第4节。游戏已确认支持英文和中文，中文按简体默认；完整双语范围与验收见该文第19.6节。

| HIGH CONCEPT / 一个轻松明亮的 2D 剑与魔法冒险 RPG：玩家在主城中组合职业、技能、装备和属性石，接取短局任务进入独立区域冒险；冒险过程需要实际走地图、探索迷宫并挑战 Boss。宠物通过副本 Boss 概率掉落的宠物蛋获得，回城由宠物师傅孵化；重复宠物可 Merge 提升自身基础能力。宠物作为独立自动战斗伙伴自动攻击与释放技能，但不作为玩家 Build modifier。副本首通后可反复挑战并解锁猎人/矿工委派；普通怪与 Boss 掉技能石和魔石，魔石可以卖钱，也可以在回城后由玩家自由选择提升五项基础属性；材料进入料理/装备制作循环。 |

## 设计一句话

**“出去冒险，带回新的装备和伙伴，然后因为一个新掉落，忍不住重新搭一个 Build 再出发。”**

## 明确不做什么

- 不做“2D 版完整 PoE”：不追求数百技能、超大天赋树、海量词缀和极重平衡成本。

- 不做纯 Vampire Survivors 换皮：玩家会真正探索地图、做任务、抓宠物、回城成长。

- 战斗需要玩家通过移动、走位、路线选择和关键操作参与；生活资源采集支持在线/离线挂机自动化，减轻重复收集负担。

- 不做开放世界、MMO、多人生存、PvP 或 Gacha 作为首发核心。

# 3. 核心循环

| 核心驱动力 / 让“掉落”改变玩家下一局的想法。理想体验不是单纯数值变大，而是：我掉到了一枚新技能石 / 重复技能石可以 Merge 升级 / 一把带有全新词条的特殊装备 / 一颗新的属性石，所以我想调整技能和装备再出发。宠物的驱动力来自副本蛋掉落、孵化、重复宠物 Merge 与战斗陪伴，而不是给玩家提供 Build modifier。 每次副本同时提供三层期待：普通怪/精英/Boss 都有机会掉落技能石；怪物稳定产出可出售或用于角色升级的魔石；副本材料用于料理与装备制作。首次通关一个副本后，还会解锁该区域的猎人/矿工委派，让手动冒险与长期资源积累互相推动。 |

# 4. 游戏结构

## 4.1 主城 / Hub

城市必须形成连贯规划：钟楼公会—召唤广场—伙伴之家为公共轴，东西大道贯通两座城门和桥，商业区与住宅区按街道组织。城墙连续围合；住宅、旅馆、工坊、药草店、市场和公会区分造型，树木与绿地有固定位置。当前地图实现与资产见 `game/whispering_forest/art/city/README.md`。

玩家在晨铃城中央被召唤。安全主城围墙内按约56×46逻辑格规划，东西桥与外侧前庭另计，五个街区设免费传送石：召唤广场、冒险者公会、工匠商业街、宠物与采集区、晨铃城门。靠近按E选择、点击或1–5传送、Esc取消；站点开局可用。城市由独立生成的地面、建筑、植物、家具、NPC和传送石素材在引擎中拼装，分别设置脚底锚点、遮挡与碰撞。

城内接任务后传送至独立副本，战斗、探索与Boss发生在副本中，完成/退出后回城交付和成长。城内石头只负责同城移动，不绕过任务前置。召唤到异世界与千年前穿越、军神无限轮回是不同机制；玩家仍是凡人。具体布局、制作单和规则见Design Full第8.1节。

- 冒险者公会：接任务、查看章节进度与区域推荐等级。

- 铁匠：装备强化、拆解、基础打造。

- 职业导师：负责就职、免费转职、职业技能组与武器适配说明；不出售技能。装备按永久基础属性要求穿戴，默认不限制职业；职业决定技能组，技能由掉落解锁并检查武器标签。

- 宠物管理：查看、编队、放生/收藏；首版只允许 1 只主战宠。

- 商人：基础消耗品与少量轮换物品。

- NPC / 剧情：每章只保留少量关键人物，控制文本和演出规模。

| 区域 | 主题 | 玩法变化 |
|---|---|---|
| CH01 A Hat and a Silent Bell | 晨铃城召唤 → 独立城外副本 → 林缘旧路 → 地下灵堂 | 就职取帽、村民救援、地下灯/排水机关 |
| CH02 Bells Beneath the Sea | 退潮海岸 → 沉没港城 → 深潮钟殿 | 海床步行、免费潮息膜、双回潮闸 |
| CH03 The Temple Beyond the Snowline | 银脊山路 → 龙巢冰湖 → 无日神庙 | 雪地救援、龙身封印、神庙时门 |

| CH05 Babel: The Stair of Winds | 现在的巴别塔遗基 → 螺旋外阶 → 云海风塔 | 真正爬巴别、云桥、风琴柱与静风环 |
| CH06 The Sunfire Crucible | 太阳环栈道 → 白金铸庭 → 恒昼炉心 | 太阳环、遮光板、三献光炉 |

| CH09 The Last Gate | 四权柄风路 → 无影长阶 → 至高圣座 → 晨铃城 | 四归时锚、多相神战、返回人间 |

每次战斗冒险不是直接进入竞技场，而是需要实际走完一定长度的地图。推荐基本流程：主城接任务与准备 -\> 传送至独立副本 -\> 实际走过区域地图/迷宫 -\> Boss -\> 回城交付。

地图中可以包含分岔路线、宝箱、NPC/事件、宠物遭遇、机关和精英怪；迷宫保持短而有探索感，避免为了“迷路”本身拉长时间。

世界采用“固定主题区域 + 半随机迷宫/房间组合”：主要地标和区域身份固定，迷宫内部可以使用模块化 TileMap 进行有限随机，提高重复游玩价值。

世界旅行原则：从召唤主城、城外副本与地下灵堂逐步进入深海、雪山神庙、千年前古城，再回现在登巴别塔，穿过天空四元素塔抵达神座。每章提升建筑尺度、环境危险或法则异象，仍保留回城生活作为对照。

龙族设定：龙是古老、稀有的生命，战斗种族一般为兽。CH03塞尔法知道神庙封印，克里兹是被枷锁控制的战斗对象；CH06沃鲁格守天空炉门。智慧古龙和剧情幼龙不进宠物池，Boss蛋只产独立魔力幼体；不再使用过去轮回的既视感解释。

# 5. 战斗系统

| **\[已定\] Half-auto Action RPG** |
|-----------------------------------|

| **玩家行为** | **设计**                                         |
|--------------|--------------------------------------------------|
| 移动         | WASD / 左摇杆；移动是主要操作。                  |
| 普通攻击     | 自动寻找合理目标并攻击。                         |
| 常规技能     | 按冷却自动释放；技能有优先级和触发条件。         |
| 闪避         | 手动；短 CD，提供无敌帧或高额减伤。              |
| Ultimate     | 每职业1个、手动释放；法师结印召唤火陨石，强调落点与时机。 |
| 交互 / 宠物遭遇 | 野外遭遇可见宠物时由玩家主动确认查看，避免完全自动化；用于点亮宠物图鉴“已见过”状态与蛋线索，不直接获得宠物本体（见 10.1）。 |

## 5.1 为什么不是纯 Survivor

- 玩家需要沿地图前进，而不是只在一个房间里坚持到计时结束。

- 任务中存在目标、分岔、事件、宝箱、宠物巢穴和 Boss。

- 地图与敌人的空间设计必须影响走位，不只是在屏幕上堆怪。

## 5.2 一局节奏

推荐单次冒险节奏：进入区域 -\> 沿地图推进并战斗 -\> 分岔探索 / 事件 -\> 进入迷宫 -\> 精英或宠物遭遇 -\> Boss -\> 奖励结算。

战斗与探索必须交替出现，避免整局都在同一屏幕刷怪。地图本身需要通过狭窄通道、障碍、危险区和路线选择影响走位。

每个战斗节点清空后触发一次远征强化三选一（见 12.2），为局内战斗提供持续可感知的即时成长曲线，弥补基础属性成长延后到回城结算带来的“打了半天没变化”问题。

# 6. Build 系统

**Build 由四个层次组成：**

| **层次** | **作用**                                        | **设计原则**                                                            |
|----------|-------------------------------------------------|-------------------------------------------------------------------------|
| 职业     | 决定四普通＋一终极技能组，技能检查武器标签 | 推荐技能武器Warrior=Sword/Axe、Ranger=Bow/Crossbow、Mage=Staff/Wand；默认穿戴只检查基础属性 |
| 基础技能 | 通过技能石掉落获得；重复技能石可 Merge 升级     | 技能石负责数值成长；技能的行为变化改由装备词条提供（见 9.2）             |
| 装备     | 强化或改变 Build，是技能行为变化的主要来源      | 优先做 build-changing affix，比单纯 +10% 伤害更重要                     |
| 属性石   | 改变玩家攻击属性                                | 地 / 水 / 火 / 风；服务区域克制与战前准备                               |

宠物不属于玩家 Build 层次。玩家 Build 由职业、技能、装备与属性石组成；宠物作为独立 AI 战斗伙伴存在。

## 6.1 属性

| 属性   | 主要影响                    | 设计方向                 |
|--------|-----------------------------|--------------------------|
| 体力   | 生命值与生存能力            | 提高容错与持续作战能力   |
| 魔力   | 魔力值 / 技能资源与魔法能力 | 支持高频或高消耗技能     |
| 攻击力 | 普通攻击与伤害输出          | 直接提升角色主要输出能力 |
| 敏捷   | 攻击速度、移动与动作效率    | 形成高速、机动型玩法     |
| 防御   | 承受伤害与减伤能力          | 提高正面作战和容错       |

| 原则 / 玩家基础属性固定为五项：体力、魔力、攻击力、敏捷、防御。首版不增加 Accuracy、Spirit、Willpower、Energy Shield 等第二层属性，除非 prototype 证明真的需要。 |
|------------------------------------------------------------------------------------------------------------------------------------------------------------------|

## 6.2 属性石

玩家可以像《魔力宝贝》一样装备属性石，改变角色攻击的元素属性。元素属性固定为四种：风、地、火、水。

属性石主要影响普通攻击以及允许继承攻击属性的技能；宠物拥有自己的攻击属性，不会因为玩家更换属性石而改变。

属性石的核心价值是改变攻击属性和区域应对策略，不把它设计成单纯的 +X% 攻击力宝石。元素克制关系沿用《魔力宝贝》的循环：地克水、水克火、火克风、风克地；具体伤害倍率在 prototype 阶段再确定。

## 6.3 怪物种族与克制

怪物种族固定为五类：人形、兽、植物、不死、邪魔。

基础克制链：人形克兽，兽克植物，植物克不死，不死克人形。

邪魔属于特殊高位种族，对人形、兽、植物、不死四类都具有克制关系。种族克制与元素克制是两套独立计算维度，最终倍率与叠加方式在 prototype 中平衡。

# 7. 职业系统

| 职业    | 技能适配武器   | 武器战斗特征             | 属性成长                         |
|---------|----------------|--------------------------|----------------------------------|
| Warrior | Sword / Axe    | 近战、范围打击、较高硬直 | 不由职业决定；玩家用魔石自由加点 |
| Ranger  | Bow / Crossbow | 远程、攻速、机动         | 不由职业决定；玩家用魔石自由加点 |
| Mage    | Staff / Wand   | 魔法、范围、远程         | 不由职业决定；玩家用魔石自由加点 |

核心原则：职业决定四个普通技能与一个终极技能的可用组；武器决定普攻模板，技能还检查所需武器类型。按本次属性穿戴的默认衔接，满足永久基础属性要求就可穿戴其他职业常用武器，但不获得其职业技能。职业不决定基础属性成长。职业穿戴限制的可选澄清见完整设计D16。

玩家的体力、魔力、攻击力、敏捷、防御由玩家自己成长。副本内击杀不提供角色经验；玩家回城后消耗魔石，自主选择要提升的基础属性。

技能使用条件为已解锁、属于当前职业、当前武器满足RequiredWeaponTag。Mage可在属性达标时持斧普攻，但其法杖/魔杖技能停用并显示原因；武器穿戴与技能适配是分开的判断，不用章节旗标限制二者。

# 8. 技能系统

## 8.1 技能石：掉落、解锁与合并

技能不以升级自动解锁、技能点购买或导师教授为主，而是作为战斗掉落物获得。副本中的普通怪、精英怪与 Boss 都有几率掉落技能石；精英与 Boss 可拥有更高掉率或更稀有的掉落池，宝箱与特殊事件也可作为补充来源。

第一次获得某种技能石时自动解锁对应技能；之后再次掉落相同技能石，可以直接 Merge 到已拥有的技能中，提高该技能等级与预设属性，例如基础伤害、范围或技能尺寸；具体成长按完整设计固定曲线。冷却成长只适用于普通技能，终极不因Merge改变满怒门槛。

最终规则：技能石负责“获得技能 + 技能等级成长”；技能的行为变化则通过装备词条实现（见 9.2）。技能不绑定主线章节，也不要求去导师处花技能点学习。掉落采用轻微目标倾向：在符合该区域掉落池的前提下，未解锁技能、当前装备且未满级的技能可获得小幅权重提升，但不做确定掉落，仍保留惊喜感。

唯一例外是第 1 章首个精英怪的保证技能石掉落（见 13.4 任务 2）：这是仅有一次的教学性保底，确保新玩家一定能看到“技能石掉落 -\> 自动解锁”的完整演示。除该教学节点外，技能石掉落统一遵循本节的概率与轻微加权规则，不再设置额外保底。

技能石等级上限、每次 Merge 所需数量与成长曲线后续平衡；首版避免给每次合并生成随机词条，以控制复杂度。

## 8.2 技能规模

**已定：每个职业4个普通技能，加1个终极技能，总计5个。** 三职业总共15种技能石，其中12种普通技能、3种终极技能。普通技能与终极都通过技能石掉落解锁、重复石Merge成长；不由导师直接授予。

| **阶段** | **技能规模** | **目标** |
|---|---|---|
| Vertical Slice | Mage 5种：4元素普通技能+1火陨石终极 | 验证四元素分工、技能石成长、装备词条、战斗积怒与满怒手动结印爆发 |
| v1及完整九章 | 15种：每职业4普通+1终极 | 同一套技能跨章节成长，不按章节另外解锁一套技能 |

| 职业 | 四个普通技能 | 一个终极技能 |
|---|---|---|
| Warrior | 弧光斩、回旋斩、破阵击、守势震击 | 星落断空 |
| Ranger | 贯风箭、散叶连射、蔓根陷阱、定标重矢 | 流星箭雨 |
| Mage | 火：萤火球；风：回风刃；地：岩星坠；水：潮汐新星 | 炎印·火陨天降：结印召唤火陨石 |

法师终极呈现为“结印→空中法阵→燃烧陨石坠落→爆炸与地面火痕”。水系潮汐新星是普通技能；地系小落岩与大型火陨石必须在尺寸、节奏、火尾和音效上区分。普通技能可同时装备的数量与技能库总数分开决定，见完整设计D07；技能数量与法师终极形式已确认。

## 8.3 怒气与终极释放

**用户已定：关卡战斗中积攒怒气，满后可手动释放终极。** 三职业统一；原型暂定满条100，每次成功施放消耗100、0MP、无固定CD。普通技能继续消耗MP并按CD自动施放。怒气不是可购买成长的基础属性。

原型基础获取：玩家普攻/普通技能有效命中每1秒窗口合计+2，普通敌人击杀+2、精英击杀+8（不叠普通），非Boss战斗节点清空+5；多段/范围命中共享窗口。宠物击杀可计，宠物命中不额外充能；Boss本体有效命中可计，但Boss召唤物、终极及其派生伤害不给怒气，具体来源边界见完整设计3.2.1。

每次新远征从0开始，同run跨房间/休息保留、满后可留着、不衰减；结束回城归0。施放前摇/结印完成前取消保留怒气，成功生成攻击时才扣100；生成后打空不退款。法师基础结印0.60s生成空中陨石，再0.90s落地；释放速度卡只缩短结印，生成时按实际动作完成扣怒。重试恢复Boss入场快照，读档恢复同run状态，不能靠失败保留额外怒气。

HUD同时显示HP、MP、怒气条、普通技能CD与终极就绪状态；满条给轻提示。怒气获取/返还装备、料理与卡牌的精确数值、保存边界和验收用例统一以 [Design Full.md](<Design Full.md>) 第3、19、20节为准；获取速度仍需原型验证。

## 9.0 属性门槛、四档品质与随机制作

**用户已确认：装备穿戴不受章节限制，是否可穿取决于玩家属性；有材料即可制作，不需要进入/首通章节；成品属性在一定范围内随机，稀有度分普通、少见、稀有、传承。** 详细规则与162件逐项需求见 [Design Full.md](<Design Full.md>) 第4节和九章装备表。

穿戴暂按“起始5点＋永久购买次数”的基础V/M/A/S/D判定，不含装备和临时Buff。材料阶t1–9只决定预算和材料来源，不是章节解锁门槛；主需求5+4(t−1)、副需求5+2(t−1)、饰品对应主属性需求5+3(t−1)。Sword/Crossbow看A/S，Axe看A/V，Bow看S/A，Staff看M/A，Wand看M/S；重甲D/V、轻甲S/D、法袍M/D。同模板需求不随随机数值/品质/强化变动，升材料阶才更新。属性不够仍可制造并存放。

普通/少见/稀有/传承默认概率50%/30%/17%/3%，标称属性区间系数分别90–110%/100–120%/110–130%/120–145%；整数上下界分别向下/向上取整后逐项均匀抽值，显示具体数值范围。四档分别有0/1/2/3条随机数值附加项，从V/M/A/S/D、暴击率、移速、怒气获取共8类中无重复抽取，具体区间/上限见完整设计。基础/特色仍是模板分类，特色固定行为不因低品质而消失，也不因高品质暗增倍率。

当前内容的全部装备配方从铁匠界面开放，无章节、调查、掉落图纸、制作等级或穿戴属性门槛；装备制造不收金币，只消耗标明的材料/底材。制作必成功，模板与特色行为确定，稀有度及数值随机。特色底材提供最低稀有度：稀有底材成品稀有85%/传承15%，传承底材不降档，但数值及附加项重抽。Q101固定起始装备是教程赠品，不代表同模板制造也固定数值。

强化+0～+3按实例实抽主属性增长、仍收金币和矿晶；特色升阶仅需目标阶材料，无首通要求，保留品质、附加项种类及随机分位，重新映射目标阶区间并重置强化。制作事务保存种子/版本/成品，退出或重复打开不能重抽已提交结果。材料转装备出售可换金币，拆解只返少量常规材料，经济不再依赖旧制作金币成本。

## 9.1 词条优先级

- 第一优先：改变技能行为，例如 “Fireball +1 projectile”。

- 第二优先：形成元素与属性石协同，例如“装备火属性石后，火系攻击触发额外燃烧”。

- 第三优先：基础数值，例如攻击力、体力、敏捷、防御。

- 避免首版做大量难以感知的细碎词条。

# 10. 宠物系统

| **\[强烈建议保留\] 宠物是最容易形成独特身份的系统** |
|-----------------------------------------------------|

| **宠物组成** | **规则**                                                                    |
|--------------|-----------------------------------------------------------------------------|
| 基础攻击     | 自动索敌并持续攻击；玩家不需要手动下达攻击指令                              |
| 战斗技能     | 自动按冷却、距离、生命值或其他条件释放                                      |
| AI 定位      | 近战、远程、治疗、控制等；通过战斗行为形成差异                              |
| 属性标签     | 元素：风 / 地 / 火 / 水；种族：人形 / 兽 / 植物 / 不死 / 邪魔（按怪物设定） |

玩家只直接控制自己的角色。主战宠物自动跟随玩家、自动索敌、自动普通攻击，并根据冷却、距离、血量等条件自动释放技能。

宠物不会给玩家提供攻击力、暴击、元素伤害等 Build modifier。选择宠物时，玩家考虑的是它自身的输出、治疗、控制或其他战斗行为。

首版同时只允许 1 只主战宠，控制 AI、寻路、特效和战斗平衡成本。 宠物获取以“刷副本 Boss -\> 蛋掉落 -\> 回城孵化 -\> 重复 Merge”为主要长期循环。

## 10.1 宠物蛋掉落与孵化

野外遭遇与宠物图鉴：地图中可能出现宠物巢穴、稀有身影等“宠物遭遇”互动点（见 11.1）。这类遭遇不会让玩家当场获得宠物本体，而是点亮宠物图鉴（10.4）中该宠物的“已见过”状态，并为该宠物蛋在本副本 Boss 掉落池中的权重提供小幅“蛋线索”加成。玩家实际拥有一只宠物，仍然只能通过下面的“击败 Boss -\> 蛋掉落 -\> 回城孵化”流程获得。

1\. 每个副本都维护自己的“宠物蛋池”。蛋池主要由该副本实际出现过的普通/稀有宠物组成，让玩家看到某只宠物后知道它有机会被带回家。

2\. 击败副本 Boss 后，有一定概率掉落该副本蛋池中的宠物蛋。蛋本身先进入背包，不在副本内直接孵化。

3\. 玩家回到主城后，将宠物蛋交给宠物师傅孵化。Premium 单机方向下不设置真实时间等待；播放短孵化演出后立即获得宠物。

4\. 每个副本的 Boss 还拥有低概率“Boss 宠”掉落/孵化结果。Boss 宠应拥有独特外观、攻击动作或技能组合，但不设计成所有 Build 都必须刷到的绝对最强单位。

5\. Boss 宠采用隐藏的软保底 / Bad Luck Protection：连续多次击败该 Boss 都没有获得 Boss 宠时，下一次 Boss 宠掉率会逐步小幅提高；一旦成功获得 Boss 宠，额外加成立即重置为基础概率。玩家不直接看到精确概率，避免系统变成机械计数，但长期刷取不会出现极端“几十次完全没希望”的体验。

## 10.2 重复宠物 Merge

重复孵化出相同宠物时，不把它变成占仓库空间的第二只普通副本，而是可以 Merge 到已有宠物中，提高宠物的基础能力。

Merge 主要提升该宠物自身的生命、攻击、防御、技能倍率等基础数值；不向玩家角色提供 Build modifier。推荐设置有限的 Merge 阶段，例如 +1 ~ +5 或星级，避免无限堆叠。

达到关键 Merge 阶段时可以给明显反馈，例如体型细微变化、技能特效增强、自动技能范围扩大或外观徽记，而不是只有面板数字变化。

Boss 宠也允许通过重复获得进行 Merge。Boss 宠基础掉率保持稀有，但软保底负责控制极端坏运气；具体基础概率、每次失败增加幅度、上限和重置规则在 prototype 中测试。

## 10.4 宠物图鉴

宠物图鉴是宠物系统的收集入口，按副本分类展示该副本蛋池中的宠物：已捕获宠物显示完整外观与基础信息；已见过但未捕获的宠物以剪影形式显示，名称留空，暗示"这个副本还有东西没抓到"。

图鉴不展示具体掉率、软保底进度等精确数值，只展示捕获/未捕获状态与 Boss 宠是否已获得，避免把宠物收集变成纯粹的概率计算行为，同时保留持续游玩的目标感。

达成阶段性收集里程碑（例如某个区域宠物图鉴全部点亮）可给予称号候选或轻量展示奖励，与称号系统（12.3）形成联动，不作为 Build 数值来源。

| **任务类型** | **目标**                                           | **复用价值**               |

| Hunt         | 击败指定精英 / Boss                                | 基础战斗内容               |

## 11.1 地图原则

- 模块化 TileMap + 手工关键节点：既控制工作量，又保留冒险感。

- 每个区域至少有 2-3 种路线模板与事件点组合。

- Boss 房、稀有宠物遭遇 / 蛋线索点（见 10.1，遭遇不直接给予宠物本体）、宝箱房可作为可复用“房间模块”。

- 不追求完全随机生成；优先做“看起来像手工地图”的半程序组合。

## 11.2 所有任务可重复游玩 / Repeatable Quest Loop

主线第一次完成时推进剧情；之后该任务/副本会以“再调查 / 讨伐 / 远征”形式永久开放，不回滚剧情。玩家可以随时重复进入同一张地图，并继续获得战斗、收集与制作收益。

故事首通只发生一次；之后全部任务以“旅途回响 / Journey Echoes”重玩。CH04重玩是记录中的古城，不再次改变现在；CH08/09是战斗回响，不让圣座投影或阿尔凯恩在正史复活。剧情桥梁、四塔释放与结局状态永久保留，正常Boss掉落继续可刷。

每次重复副本都必须保证“有进度”：即使没有出现稀有技能石或宠物蛋，玩家仍然会得到魔石、材料与地区调查度，材料和金币也能用于采集队升级，因此尽量避免出现完全白刷的一局。

奖励分成三层：① 高频基础收益：魔石、普通材料；② 中频成长收益：技能石、装备素材、稀有材料；③ 低频惊喜收益：宠物蛋、Boss 宠、稀有/传承装备、龙族相关特殊掉落。三层奖励同时存在，让短局和长线目标都成立。

重复游玩不依赖每日登录、体力或限时 FOMO。目标是让玩家因为“下一局可能有新组合/新掉落，而且每局都在推进成长”而主动继续，而不是被时间门槛强迫上线。

## 11.3 可升级的猎人 / 矿工自动采集

按用户新增要求，资源委派改为现实时间推进的挂机自动化，支持在线、战斗暂停和离线。首章首通交任务后免费获得布兰的猎人队与托克的矿工队；一处地区必须由玩家亲自首通，之后两队才能前往该章安全采集点。队伍等级不额外锁已首通地区。

猎人巡林、采药，带回本章 H 兽材/纤维与 P 植物，服务料理、轻甲与饰品；矿工开采 O 矿物与 C 水晶，服务武器、防具与强化。各队可选择均衡50%/50%、第一种优先75%/25%或第二种优先25%/75%。只有36种常规材料可产出，不自动刷魔石、技能石、宠物蛋、Boss专材/装备、剧情物品、玩家经验或怒气；派遣免费，无每日体力或持续工资。

两队独立Lv1–10，完成一批获得1点本队累计经验；达到经验/首通条件后用金币和常规材料手动晋升。Lv1每线30分钟4件；Lv2增至5件；Lv3选一项对应材料+20%的专精；Lv4第二线路；Lv5制作目标自动补货；Lv6为v1上限；Lv8第三线路和24小时货仓档；Lv10每线20分钟8件。每级具体费用与效率见 [Design Full.md](<Design Full.md>) 第6.3.2节，两队升满合计9,120金币、484常规材料。最高区域调查加成+10%与专精相加，不受远征卡或Boss指数成长影响。

选好地区与重点后自动连续采集，无需逐批领取或再次派遣。已完成货物进入各线路货仓；登录、回城、打开管理页自动转入公共材料库。货仓从8小时档升至12/24小时档，按完整批数取整并显示真实容量；满仓暂停，归仓自动续采，无腐坏。在线和离线相同，关闭游戏后在下次载入计算产出，不要求游戏一直开着。

Lv5起可以设置“做几份料理/一件装备”或材料库存目标，两队自动按缺口选择已开放地区与采集重点，并扣除已有、货仓及在途材料避免重复补货。多个配方先汇总材料需求，设为持续库存目标，消耗后自动补回；所有目标满足或队列空则回常驻路线或休息。目标可暂停/删除，不自动制作或支付升级费用。装备目标的专材/底材不足另行提示（装备制作无金币费），料理/强化费用按各自规则；采集不能替玩家完成Boss挑战。

完整升级表、九章安全采集点、产量/小数余量、货仓上限、离线/异常时间/崩溃恢复、旧委派迁移和所需素材见完整设计第6.3节。此规则覆盖旧版按通关次数推进的委派，宠物孵化仍无现实时间等待。升级与仓储参数为原型默认值，后续根据材料实际消耗调整。

## 11.4 副本异变与地区调查度

为了让同一任务重复玩仍然有变化，每次进入副本随机抽取 1-2 个“地区异变”，并从 2-3 套路线/房间组合中选择一种。异变示例：暴风雪、沙暴、魔石富集、精英增援、龙影出现、稀有采集点、隐藏宝箱房、路线塌方、特殊商人。异变必须至少改变路线、敌人或奖励中的一项，不只是 +10% 数值。

每个区域拥有“调查度 / Mastery”。重复通关、发现隐藏房间、击败稀有精英、遇到龙族事件都会提升调查度。达到里程碑后可解锁更高威胁等级、额外路线、料理配方、装备配方推荐、委派效率或特殊挑战。

同一副本的核心地标、剧情节点与 Boss 身份保持固定，随机变化只发生在支路、房间连接、精英组合、事件和奖励点。目标是“每次熟悉但不完全一样”，而不是生成容易迷路、缺乏记忆点的纯随机地图。

高威胁等级继续复用同一地图资产，但增加更危险的敌人组合、Boss 招式和更好的技能石/宠物蛋/稀有材料概率。玩家可自由选择风险与收益，不强迫所有人刷最高难度。

# 12. 成长系统

## 12.1 局外永久成长

- 角色不通过副本内击杀经验升级。怪物不会在副本中直接提升玩家等级；玩家把冒险带回主城的魔石用于基础属性成长，并由玩家自己选择提升体力、魔力、攻击力、敏捷或防御。

- 技能主要通过技能石掉落获得；重复技能石 Merge 提升技能等级。

- 装备掉落与升级：装备词条（见 9.2）是技能行为变化的主要来源。

- 宠物收藏与培养：Boss 掉落副本宠物蛋 -\> 主城宠物师傅孵化 -\> 重复宠物 Merge 提升基础能力；首版避免复杂繁育、性格、IV。

- 章节 / 区域解锁。

## 12.2 局内临时成长：远征强化 / Expedition Boon

**用户已定：远征强化以通用参数加成为主，分白卡、金卡、紫卡，高阶更稀有。** 顺序为白＜金＜紫，基础出现概率暂定70%/25%/5%；与技能石Merge等级分开。每个非Boss战斗节点清空后仍三选一，Boss/终局节点提供即时补给；所有强化在远征结束后重置，不增加永久五属性购买次数。

v1设计20个通用类别，每类三档，共60个参数组合；切片先做8类×三级。核心包括技能面积、释放速度、额外投射物、移动速度、最大生命、暴击率、技能伤害、怒气获取，另有暴伤、普攻速度、防御、减伤、最大魔力、回蓝、受疗、抗控、闪避CD、魔石/材料产量、射程/飞速。卡作用于所有当前及之后装备的适配技能，按标签过滤，不绑定某个职业或火球专属ID；玩家卡不直接给宠物属性。

| 示例通用强化 | 白卡 | 金卡 | 紫卡 |
|---|---:|---:|---:|
| 技能面积 | +15% | +30% | +50% |
| 技能释放速度 | +10% | +20% | +30% |
| 普通技能额外投射物 | +1 | +2 | +3 |
| 移动速度 | +5% | +10% | +15% |
| 最大生命 | +8% | +16% | +25% |
| 暴击率 | +3个百分点 | +6个百分点 | +10个百分点 |
| 技能伤害 | +10% | +20% | +35% |
| 怒气获取 | +10% | +20% | +35% |

每轮三张不同类别：先筛合法类别/档位，再抽稀有度与类别；同档及低档不重复给，更高档可作为升级出现。高档替换低档而非累加，例如技能伤害白升金为总+20%；选升级占一次选牌。已持紫卡的类别不再出现。档位空池时按剩余权重归一化，合法类别不足用即时补给填满；保存候选与选择事务，退出不重抽。

“面积+50%”按面积计算，半径乘sqrt(1.5)；“释放速度+30%”令前摇和普通CD除以1.30，技能伤害/MP及终极100怒气门槛不变。额外弹道每发35%对应原生单发伤害、每敌最多1发追加命中，不增加火陨石颗数或箭雨波数。各项叠加/上限、装备组合、稀有度例算与中英卡名见 [Design Full.md](<Design Full.md>) 第3.5节，全部为待实测初值。

卡面用颜色、I/II/III徽记及本地语言文字共同辨级，显示受益技能和“当前→升级后/净增”，结算展示本局卡类与最高档。九章共用同池，各章同时验证无紫卡与含紫卡组合；不得以抽到紫卡为通关前置。特殊分裂/回返/转换保留在装备行为中，临时卡负责通用成长与局内选择。

## 12.3 称号系统

加入类似《魔力宝贝》的称号系统。玩家可以通过主线推进、任务、探索、Boss、宠物捕捉、特殊事件和长期成就获得称号。

称号既可以代表冒险者声望阶段，也可以是特殊事件或挑战留下的身份记录；玩家可以从已获得称号中选择一个展示在角色名称附近。

称号系统以身份感、收藏感和长期成长反馈为主，不作为核心 Build 数值来源，避免玩家只因为属性最强而被迫使用某个称号。

示例方向：初来乍到的冒险者 -\> 被认可的冒险者 -\> 王国知名冒险者；同时存在“森林守护者”“迷宫探索者”“稀有宠物收藏家”等特殊称号。具体名称后续随世界观统一。

## 12.4 魔石：货币与基础属性成长资源

普通怪、精英怪与 Boss 都会掉落魔石。魔石是副本中最稳定的基础战利品之一，用来保证每次出征都有可积累的收益。

玩家回城后可以二选一处理魔石：① 卖给商人换金币，用于购买、料理、强化和采集队升级等经济行为；装备制造只扣材料；② 在角色成长界面消耗魔石，直接选择提升体力、魔力、攻击力、敏捷或防御。这个选择让“当前经济需求”“想补哪项属性”和“长期战力成长”形成自然取舍。

副本内不出现传统“打怪即时升级”。基础属性成长集中发生在回城阶段，让战斗 HUD 更干净，也强化“带着战利品回城 -\> 自己决定如何成长 -\> 再出发”的节奏。

每项基础属性都拥有独立成长等级，提升所需魔石数量采用逐级递增曲线；玩家可以专精，也可以均衡分配。高级区域和高威胁副本产出更高价值/更多魔石，数值需要保证正常推进不会被迫长期刷低级地图。

### 12.4.1 指数Boss血量与大数字成长

**用户已定：Boss HP指数增长，强调伤害与数字的爽感。** 原型采用`BossHP(c)=4,000×3^(c−1)`：九章依次为4,000 / 12,000 / 36,000 / 108,000 / 324,000 / 972,000 / 2,916,000 / 8,748,000 / 26,244,000。T1/T2在本章T0血量上分别乘1.30/1.65，不再重复乘章系数。

玩家输出随实际武器阶位t使用`K(t)=2.4^(t−1)`放大武器预算及攻击/魔力的伤害贡献，武器取得/升阶会带来真实的大数字提升；进新地图不自动升武器，回旧图不自动降伤害。普通/精英HP同步适配，宠物输出按现有训练等级增长，治疗用独立未放大的支援基值，玩家HP与敌方ATK仍控制在原有容错范围。

目标从首章几十/几百伤害成长到后期数万/百万；终极与暴击有更清楚的飘字、音效和血条扣血反馈。伤害显示来自实际扣血，提供中英完整数字/紧凑单位设置。普通Boss仍以75–120s、最终含核心/转阶段150–210s作为测试目标，不以满级技能或紫卡为通关前置。具体武器/敌人/宠物数据、精度和算例统一见 [Design Full.md](<Design Full.md>) 第2.3.1、4、5、19.1.1与20节；×3与×2.4是待实测的原型参数。

## 12.5 材料、料理与装备制作

怪物、采集点、宝箱、猎人委派和矿工委派都会提供材料。材料按用途分为料理素材、兽/植物素材、矿物/水晶素材、Boss/稀有素材等。

料理：用常见食材制作短期冒险增益，例如最大生命、元素抗性、移动速度、回复能力、宠物生存等；避免做成必须每天吃的消耗负担。

装备制作：矿石、皮革、水晶和区域稀有材料用于制作或强化武器、防具、饰品。Boss独有素材作为特色装备配方消耗，不是解锁图纸的条件；材料齐即可制作，成品按四档稀有度随机数值并保留模板行为。

核心经济循环：主动刷本拿技能石/魔石/稀有掉落 -\> 首通解锁委派 -\> 委派补充常规材料 -\> 料理/制作帮助挑战更高威胁副本 -\> 获得更好的技能石、宠物与装备。

## 12.6 进度可视化

设计目标：把“达到里程碑才提示”的隐藏进度，转化为回城结算画面上可见的“还差多少”进度条，利用目标趋近心理持续给玩家“下一局值得再来”的具体理由。

可见进度（结算画面展示当前值与下一里程碑）：

- 地区调查度（11.4）：展示距离下一个里程碑（更高威胁等级 / 新路线 / 料理配方 / 装备配方推荐 / 特殊挑战）还差多少调查度。

- 宠物 Merge 阶段（10.2）：对已拥有至少一只、尚未到达 Merge 上限的宠物，展示“还需 N 只重复宠物蛋即可提升至下一阶段”。

- 采集队等级（11.3）：展示猎人/矿工累计经验、下一等级收益、缺少的金币/材料与首通条件；每完整采集批次给经验，领取不重复给。独立采集报告显示离线收获、货仓状态与补货目标。

结算画面只显示本局有实际推进、且接近下一个里程碑的 1-3 条进度，避免同时铺开所有区域 / 宠物的进度条造成信息过载。

不可见进度（维持隐藏，不因本节改动）：Boss 宠软保底（10.1）不展示任何精确概率或计数，避免把稀有宠物获取变成机械计数行为；技能石掉落权重（8.1）同样不展示具体加权数值。这条界线是有意保留的——“半可见”指暴露确定性的成长进度，而不是暴露概率类系统的运作细节。

# 13. 故事与章节 / Story v3

## 13.1 故事与九章递进

**本次按用户纠正采用Story v3.1。** 玩家在晨铃城被召唤，再从城外副本走到神域，最后阻止军神阿尔凯恩打开时空之门、让世界陷入无限轮回。阿尔凯恩早已是军神，以将军形貌走在人间；主线没有玩家登神或将军后来成为秩序之神的成长线。环境仍按召唤主城/城外副本/地下灵堂→海底→雪山神庙→千年前古城→返回现在→巴别塔及天空四塔→神座递进。首发前四章完成救城与归乡，后续完整篇揭示并阻止轮回计划；赛维恩仍是普通神官，萨维洛斯仍是独立守门投影。

**故事起点**：玩家是一名被召唤到异世界的普通旅人，在晨铃城中央的召唤广场苏醒，梅尔负责接应。城中丧钟无风自鸣，地下灵堂渗出咸水，城方因此向界外求援；玩家可先熟悉安全主城，并不被立刻强迫战斗。与导师接取就职任务后，才被传送到独立的城外哥布林副本，取得帽子后回城交付。随后第一件大事是把失踪的孩子和居民带回家。灵堂潮纹指向海底，沉钟铭文指向雪山，山顶神庙保存通往千年前的门。开场的跨世界召唤、CH04的有限历史穿越、军神欲发动的世界重置是三件不同的事；召唤不代表玩家成神、命定唯一或已经历轮回。

**真正发生的事**：千年前，军神阿尔凯恩以将军形貌守护阿斯特拉，爱上凡人水工师艾妲。玩家在大潮当日与他们共同救援，见过她修闸、嫌面包烤焦、催他收起兵器吃饭的样子。救援之后两人还有过许多年的生活；艾妲继续修桥、教徒弟，最终自然老去，军神却仍不老。他想回到救援结束、两人在归人桥边约好吃晚饭的那个傍晚，并让它永远不会结束。爱人的姓名、职业和自然离世为本稿具体默认，用户已确认的是军神因思念爱人而试图开启无限轮回。

玩家不是预言指定的唯一勇者。长久以来，军神用记忆术保存两人的旧物，后来将巴别塔之上的四元素设施改造成时空之门的供能系统，签下《归时誓约》并束缚四女神。为了与真正的艾妲永远相伴，他准备把整个现在覆盖成那个傍晚，每到结束便自动回到开头；他保留记忆，艾妲和世人却无法走进新的明天。当前尚未发生第一次全世界重置，前章的异常是抽能和时间泄漏。玩家理解他的失去，却必须阻止他抹去千年来其他人的生活，也保护艾妲后来自己走过的人生。结局关闭时空之门，让现在继续；玩家回城，军神必须留下来面对失去与自己造成的后果。

### 13.1.1 穿越规则与可观察的因果

**CH04神庙时门**只通往千年前大潮当日的一个固定窗口，是双生钟锚维系的一次有限往返。玩家和伊诺进入真实过去，赛娜守现在；完成救援后沿原锚返回，现在只提交一次因果更新。门的时间坐标固定，不能随意选择艾妲的人生阶段，也不能把原生于过去的人带到现在。过去的艾妲会继续自己的生活，CH04回程关闭这条通道；重玩只有记录回响。剧情阶段没有现实倒计时，整理装备或离线不会使救援失败；任何战斗技能都不是门的钥匙。

**CH09军神的时空之门 / Gate of Time**是覆盖整个世界的另一个装置。它以四元素权柄为燃料，以两人约饭的傍晚为坐标，用《归时誓约 / Oath of Return》将一个暮钟周期（剧情约一小时）首尾相接。第一轮开启就会覆盖现在及其千年发展，之后每到晚钟便自动回到同一个傍晚，无自然终点；军神凭主锚保留记忆，其他人每轮从同一状态开始。即使艾妲在一轮里作出不同选择，重置仍会擦去她之后的经历。门能重写真实历史，代价来自对整个世界的覆盖，不用“复活的只是幻象”弱化军神的选择。

军神想要的是不再分离的共同生活；一段有返程终点的往返或一段旧录影不能满足这个愿望。神力也有领域边界，战斗权柄不能直接逆转时间，所以他夺取四塔来扩大时门。玩家在第一次世界重置前阻止他；倒流声、先行动作和Boss招式回放都是局部泄漏，不表示世界已经循环了无数次。死亡读档、暂停、离线结算和旅途回响均不是正史轮回。

四塔释放不等于核心立即归零。预储力量是终战仍必须发生的原因；四锚击破取消自动补给与世界同步，军神只能以有限剩余神力强撑门隙。胜利使其失去维持能力，门在首次覆盖提交前关闭。开门进程随Boss阶段演出，无隐藏真实时间倒计时、无强制DPS失败线；战斗失败按本阶段快照重试，不发生一次世界重置。

主线是一次有限改写：大潮仍然发生，玩家不替军神签任何归时誓约，玩家修好排水闸、打开避难道，救出下城区的人并让他们留下真实名册。归人桥位于古城下城区通向内陆避难高地的路上，与晨铃城的溪桥是两座桥。CH02在潮息灯旁先展示断桥遗基与“下城区无人归来”的碑；CH04从原神庙时门回到现在，赛娜带玩家经已开放的海岸驿站查看同一地点，再回城。过去修通避难道，让获救居民后来维护了这座桥；现在的完好归人桥也接通巴别塔遗基。返回后，现在的旧断桥变成仍被使用的“归人桥”，档案从“下城区无人归来”变成有姓名的救援记录。玩家、伊诺、钟锚保存旧版本记忆；其他现在的NPC记得改写后的历史。关键信息用成对地标/名册对照展示，不要求玩家靠长段设定解释理解。

过去的物资、配方、采集点都不成为必需的限时绝版内容。艾妲在本次救援后继续生活并自然老去；两种有限历史版本都不把她的死亡改成玩家迟到或漏做支线的惩罚。CH04的H/P/O/C在回到现在的古城保护区同样可得；任务钟锚不能卖、不能消耗于装备制作。主线仅一种成功走向，支线改变纪念物和个别回城台词，不分叉成多条主结局。战斗失败只按原任务恢复规则重试，不产生第二条世界线，也不复制装备、调查度或采集收益。

故事重玩使用“旅途回响 / Journey Echoes”：CH01救援不再次绑走诺诺，CH04是记录中的古城而非再次改写现在，塔守卫和最终神战是训练回响。首通旗标、现在的桥、名册与结局永久保留；重复打Boss仍正常出装备、材料、蛋，不能把叙事的一次性误写成掉落只给一次。

### 13.1.2 对话与演出基准

各章下方提供可录入的**中文对白与英文工作译文**，覆盖主线接取、途中发现、交付、Boss前后与回城。文本ID使用`story.v3.CHxx.*`；首次主线播放、重玩默认跳已读，均可在日志回看。单段一般2–4句，每句配一项可见动作或物证；一次连续站桩说明目标不超过45秒。玩家态度选项只改紧接的一句回应，不改变主线或资源奖励。

米娅讲吃饭、欠账和人是否回来；伊诺从引用祷词变成亲自作判断；赛娜先问证据，再下结论；罗兰总先确认撤离路线；赛维恩是真心照看村民的普通神官，不再与萨维洛斯共用身份。四女神分别关心呼吸、火种、承重与记忆，语言各异；艾妲先谈自己的工程、徒弟与晚饭，恋爱通过两人具体相处呈现；阿尔凯恩从克制的思念到承认愿用世界换一个傍晚，败后仍悲伤，不因一句劝说立即释怀。先让角色对正在发生的事作反应，再揭示设定。

## 13.2 通关后的情感目标

结局后城里出现可交互的归人桥纪念牌、恢复转动的水车、雨后新芽和古城救援名册。玩家可以继续造装备、养宠物、安排猎人矿工与刷回响；这些生活系统本身就是被保住的日常。第一章的哥布林帽子在就职时已经交付，结局导师把同造型的纪念帽挂在登记站墙上，作为场景陈列，不把原任务物品变成免费装备或重新开启试炼。



## 13.3 角色与任务执行

主城是晨铃城。赛维恩是真诚的普通神官，萨维洛斯是独立守门投影；伊诺随玩家穿越，赛娜留在现在守锚；艾妲、洛恩属于千年前的古城。阿尔凯恩当时已是军神；艾妲是他的凡人爱人，在CH04后仍有自己的漫长生活，CH06/08用记录展示后来人生。全部角色弧线、主城状态、逐件素材与系统数据见Design Full第8节。以下给出九章任务与完整关键对白；第4节装备、采集和技能规则不被剧情门槛覆盖。

## 13.4 第1章《城外的帽子与无声的钟》 / A Hat and a Silent Bell

晨铃城召唤 → 独立城外副本 → 林缘旧路 → 地下灵堂。先让玩家认识会回来的家。城里先出现具体的失踪、渗水与坏掉的木偶，结尾只揭示“水来自海底”，不提前讲解众神战争。

本章Boss：军神·阿尔凯恩。阿尔凯恩不被收入宠物蛋；掉落是归时残环与独立魔力幼灵。Boss降到0HP表示失去维持门环的战斗能力，不表示恋人复活或军神必然死亡。玩家完成关闭核心的交互；四女神收回被夺取的供能权限，销毁世界回返结构，阻止首次覆盖，军神失去重启这扇门的手段。他仍活着、仍思念艾妲，不因一句劝说突然释怀；最后接受眼前的门必须关闭，后续需协助修复四塔。门中只有记忆定位显出的旧城桌影，艾妲不穿门现身替他免责。镜头回城：伊诺公开归时仪式记录与救援名册，赛维恩点灯，米娅递汤，导师挂纪念帽；玩家始终是凡人，今天之后有新的明天。

四锚按固定风/火/地/水顺序交互暴露，每锚880,603HP，总3,522,412；任何普攻可打，无四元素技能硬门槛。失足按安全锚回收；机关在主线只提交一次，Boss重试不会再给锚奖励。

## 13.13 对话实施规则

每个主线Q有接取/现场/完成三阶段，支线有专用完成台词；home在当章关键完成后回城触发，远程角色使用锚通讯。日志可回放已读对白，重玩不重复长演出；过去的NPC只在过去/回响出现。关键物证与机关必须由玩家实际完成，跳过对白不自动完成任务。共用生产NPC/导师/结局日常对白见Design Full第8.3节。

# 14. 美术方向

| **Bright / Cute / Cozy Fantasy / Nostalgic JRPG** |
|---------------------------------------------------|

- 2:1 isometric斜视、64×32菱形地块，角色2–3头身；越后期越强调神域尺度、规则几何与留白，保持危险预警清楚。

- 环境按章递进：村庄暖木与墓砖、深海青蓝、雪山灰白、千年古城暖铜、云海圣白、太阳金、悬庭土金、星水深蓝、神座留白。危险不等于始终黑暗，神圣不靠满屏发光。

- 怪物偏可爱或奇幻，不走血腥与写实恐怖。

- 角色本体可以小，但技能特效可以明显大于角色，制造“低成本 + 高爽感”。

- UI 使用自然材质、木质/羊皮纸/魔法水晶元素，但保持现代可读性。

# 15. 音乐与音效

- 音乐目标：2000 年代 JRPG 的旋律感、童话感、温暖与冒险感。

- 主城：Flute / Pizzicato Strings / Accordion / Acoustic Guitar / Light Percussion。

- 森林：木管、Marimba、轻弦乐；Boss 增加 Brass、Snare、Choir 或更强打击。

- 坚持“可记住的旋律”，避免整张 OST 都变成纯 ambient。

- 只参考《魔力宝贝》的情绪与配器方向，不复制具体旋律、主题动机或编曲。

- 技能音效优先区分元素和强弱层级；掉落、稀有宠物、稀有装备词条需要独特反馈音。

## 16.1 英文与中文

游戏正式支持English与中文，中文先按简体执行。两种语言覆盖UI/教程、全部章节/任务/对白/字幕/证据、技能石/装备词条/宠物/材料/配方/料理/强化卡/称号及结局文本；每个发布范围双语同步交付，不只翻译菜单。

标题和暂停设置提供“Language / 语言”，选项始终显示“English”“简体中文”；首次按环境选择，之后尊重手动设置。切换即时刷新，不重启、不改变存档、任务或怒气。文本使用稳定key与参数，数值从同一游戏配置生成；文字不烘焙进图标，地图字样单独做可替换层。

中英字体、长英文换行、中文缺字、按键占位符、复数、语言切换与剧情线索理解均纳入验收；完整规范、共用术语及15种技能的英文工作译名见 [Design Full.md](<Design Full.md>) 第19.6节。首版保留短语气音，故事提供中英文本/字幕，配音范围不扩大为全角色双语配音。

# 21. 下一步 Prototype 顺序

1\. 只做一个 Mage 角色：移动、自动攻击、闪避。

2\. 完成 1 个法师基础技能的技能石流程：怪物/宝箱掉落 -\> 首次解锁 -\> 重复掉落 Merge 升级；技能来源不绑定剧情或导师。

3\. 做 3 种敌人 + 1 个简单 Boss，验证战斗是否有压力。

4\. 加入 1 只 Fire Slime 宠物：自动索敌、自动普攻，并按条件自动释放技能。

5\. 加入完整最小掉落循环：普通怪/Boss 有几率掉技能石 + 稳定掉魔石 + 基础材料；回城可把魔石卖钱，或自由选择提升 1 项基础属性，并能用材料做 1 份料理与 1 件装备。

6\. 做一条 8-10 分钟 Whispering Forest 任务路线，并让首通后可立刻重复挑战；至少准备 3 种地区异变与 2 套路线/房间组合，连续试玩 5-10 次验证是否仍然“熟悉但不完全一样”。

7\. 首通 Whispering Forest 后免费解锁猎人/矿工各一队，验证Lv1–2、自动续采/归仓、离线货仓和经验/升级；只产常规材料，独立测试时钟覆盖满仓与恢复。  
8. 主城布局、建筑分型、完整门墙与通行在首章切片中一并完成，再扩展剧情与更多章节内容。
