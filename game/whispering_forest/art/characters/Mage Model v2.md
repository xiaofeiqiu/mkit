# 玩家模型 v2 · 晶石魔杖

历史版本，已由 [竖握长法杖与正式动作记录](Character%20Production.md) 取代；下述短魔杖和独立角色渲染参数不再作为当前规格。

2026-09-06。针对玩家外形仍像旧模型、持物像普通棍子的反馈，重建角色网格并重新导出、接入游戏。

## 实际变化

- `mage_sculpt.gd` 删除旧模型的网格，保留可编辑关节，重新建立脸颊、下颌、眼睛、眉毛、鼻子、嘴角、成束头发、披肩、分层短袍、手指、靴子和腰侧书本。曲面使用明确的法线，减少球体拼接和生硬切面。
- 魔杖具有缠绕握柄、金属尾饰、弯曲杖身、金色嵌线、爪座与蓝色切面晶石。武器朝局部 −Y 延伸，抬手施法时由晶石端指向目标。持杖手有环握手指和对握拇指。
- 沿用关节动画的重心、抬脚、视线、衣摆、施法前摇和收势；重新烘焙 11 个动作 × 8 个方向 × 8 帧，共 704 帧。八向均旋转同一个三维模型，不镜像贴图。

## 加载与导出

- 源模型：`mage_sculpt.gd`；关节及表演：`character_rig.gd`、`expressive_rig.gd`。
- 游戏实际加载：`assets/characters/mage-v2/mage-*.png`，由 `scripts/combat/performance_frames.gd` 读取；头像和动画工作室也读取新版。旧素材仅保留供对比。
- 导出：`tools/bake_performance.gd -- --mage-only`，使用 Godot compatibility 图形渲染，再执行 Godot 导入。
- 固定正交俯角 30°，相机 `(0,6.30,8.660254)` 看向 `(0,1.30,0)`，输出密度 80 px/模型单位。4× MSAA、真实透明背景。普通帧 256 px，原点 `(128,218)`；攻击/移动施法 320 px，原点 `(160,250)`；倒地 384 px，原点 `(192,282)`。扩大画布同时同比扩大正交视野，保持人物大小和脚底位置。
- 本次保持已有角色渲染舞台参数：冷色环境光 `c5d5ec / 0.58`，主光 `fffaf3 / 1.10 / (-42,-35,0)`，辅光 `9ebfe8 / 0.32 / (-20,140,0)`。这些参数记录在角色导出器中；全场景共享配置和城市素材三维重建仍属另行推进的工作，本次不宣称全场景已完成统一验收。
