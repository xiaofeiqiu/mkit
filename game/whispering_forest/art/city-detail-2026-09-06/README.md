# 晨铃城 · 材质、体积与街道细节修订

2026-09-06。独立美术样件与验收规范。用户本轮补充：**人物、建筑、树木与设施共用比例；光源固定在画面左上；路沿需要切角、弯段与局部退让。**

本目录与当前地图分开，带 `.gdignore`，不被 Godot 当作运行素材导入。这里的 PNG 是生成后的视觉样件，尚未完成模块裁切、锚点标定、碰撞和运行场景接入。没有修改主任务正在编辑的场景、脚本、既有素材或设计总文档。

## 1. 这次要纠正的具体问题

已有 `art/city/prompts.json` 广泛使用统一蓝色屋顶、`no grunge`、干净浅色石材等要求，压缩了建筑之间的差异和使用痕迹。新规范取消这些限制，以**结构清晰、材质有层次、磨损有来源**替代统一清洁外观。

现有地面脚本把道路外扩后铺一层浅色平面，尚未形成路沿立面。增加纹理无法替代这层高度。现有建筑精灵也没有完整的朝向变体选择。以下接入要求必须同时解决结构和素材问题。

| 用户参考中成立的细节 | 新规范 |
| --- | --- |
| 房子沿街整齐排列，但能看到不同面 | 门朝向所服务的街道，四种世界朝向独立绘制；后墙有自己的窗、排水、服务入口 |
| 蓝瓦、红瓦、灰石之间有变化 | 按建筑功能和街区组织配色，保持城市统一的石材、光照与色彩明度 |
| 树冠亮面、暗部成团 | 区分树种、树龄和轮廓；统一光向，叶丛下方留暗部 |
| 道路、人行道、绿地边缘有层级 | 车行道低、人行道高；路沿有顶面、立面、接缝和投影 |
| 路口轮廓切角并围绕景物退让 | 设置切角、弧段、内凹入口和广场扩宽，保留连续可行走空间 |
| 墙门结实而略旧 | 先做墙厚、门洞深度、垛口和基脚；再做灰缝、修补、流水痕和局部苔藓 |

## 2. 统一投影、尺寸与光照

### 2.1 世界坐标与朝向

地图保持 2:1 斜视投影：`screen_x = u - v`，`screen_y = (u + v) / 2 - elevation`。建筑的墙线、屋脊、围栏沿同一组世界轴布置。不得通过旋转一张屏幕精灵改变房屋朝向，也不得随意拉伸宽高去贴合地块。

正式朝向保存为 `+u / -u / +v / -v`，不是依靠模糊的“左房子／右房子”。本目录文件名的 SW/SE/NE/NW 只是**画面中入口朝向**的阅读提示：前两个入口可见，后两个入口在远侧，展示后立面。它们是四种建筑的方向样件，并非同一建筑已完成四向复用。

### 2.2 比例尺

以成人 1.70 m 为共同标尺，先定建筑和树木的物理尺寸，再设置导入比例。下列屏幕高度以成人站立高度 72 px 为**建议基准**，即竖向约 42.35 px/m；它不是当前运行项目已标定的数值。地面长度仍通过地图投影换算，不能把这个竖向换算系数直接当作地面格宽。

| 对象 | 物理尺度 | 建议竖向屏幕尺度 | 检查重点 |
| --- | --- | --- | --- |
| 成人 | 1.70 m | 72 px | 玩家、成人 NPC 共用基准；姿态造成的高度差单独考虑 |
| 普通入口 | 高 2.10 m，宽 1.0–1.4 m | 高约 89 px | 人能自然经过，门不会比人低或像城门 |
| 民宅单层 | 3.0 m | 127 px | 层高指地板到地板，不等同整段外墙 |
| 两层房屋含屋顶 | 6.5–8.0 m | 275–339 px | 门和窗不随不同源图画布而任意改变 |
| 草药店／面包坊门阶 | 每级高 0.15 m | 每级约 6 px | 台阶贴入口，保持水平且能接人行道 |
| 三种庭院树 | 3.8 / 5.0 / 6.8 m | 161 / 212 / 288 px | 比较树干、冠幅和旁边的门窗，不只比较总高 |
| 普通城墙含垛口 | 5.2 m | 220 px | 墙厚建议 1.2–1.6 m，能容纳墙顶通道 |
| 城门塔 | 8.0 m | 339 px | 门洞净高 3.2 m，塔和城墙有明确层级 |
| 路沿 | 高 0.10–0.12 m | 高约 4–5 px | 在游戏倍率下仍能读出立面 |
| 长椅 | 座高 0.45 m，长约 1.6 m | 座高约 19 px | 不可为了“看清”而放大成成人腰高 |

导入时保留 source PNG，标记实际内容边界、地面接触锚点、门洞上下沿、屋脊/树顶及物理尺寸。**禁止按整张 PNG 的宽度统一设为 330 px，也禁止仅对齐图片底边**：透明边距、阴影长度与屋顶悬挑都不是占地尺寸。常规缩放保持宽高比；超出正确比例较多时重新生成或修整结构。

表中“竖向屏幕尺度”指物体在同一地面投影位置上的高度差，**不是整张精灵图片的外接框高度**。斜视建筑的图像还包含地块纵深、前后台阶与投影；不能把 PNG 总高压到表中数值，否则门和人会一起失真。

### 2.3 固定左上光源

- 主光从画面左上照来，所有素材的地面投影朝右下；基准太阳高度约 45°。这是美术约定，正式阴影在统一世界光向下计算。
- 朝上的顶面受光，面向左上光源的墙面较亮，背光面保留偏冷的环境光。转动建筑不会转动太阳。屋顶两个坡面按实际朝向区分明暗。
- 接触处最暗：墙脚、檐下、窗洞、树根、长椅脚。大面积阴影可读出材质，不用整片纯黑。
- 树叶用亮／中／暗三组冠层组织体积，枝叶内部和冠下明显压暗，亮叶集中在迎光外缘。
- 墙、树、房屋的投影长度随高度变化，软硬程度统一。模块接入后不得把素材里烘焙的长投影和引擎投影叠加两遍。
- 明暗一致指共同的光照关系，不是每个表面的 RGB 相同。红瓦的阴影仍应可识别为红瓦。

## 3. 建筑：不同立面、配色与生活痕迹

样件包含面包坊、药剂店、住宅后立面、工坊后立面。正式建筑库每个可环绕的基础建筑至少需要四向；同一建筑四向必须保持门窗、烟囱、屋脊和增建部分的空间对应。允许街区内复用基础模块，主要服务建筑需有独立轮廓和入口识别。

| 街区／建筑 | 主屋面 | 墙体与副色 | 有来源的细节 |
| --- | --- | --- | --- |
| 面包坊、集市住宅 | 柔和陶红瓦 | 暖白灰泥、灰石基脚、少量绿窗板 | 烟囱附近积灰、常走台阶圆角、局部替换瓦 |
| 药剂店、庭院住宅 | 灰绿瓦 | 浅石墙、少量梅紫窗板 | 排水口附近轻微水痕、入口草药盆、檐下阴影 |
| 老住宅、旅店 | 暗红／灰紫瓦 | 浅灰泥、木构、局部补墙 | 后院柴堆、不同年代修补、窗台下灰痕 |
| 工坊 | 炭蓝／蓝灰石板 | 灰白石块、少量铁锈红木饰 | 装卸门磨损、烟道污迹、规则存放的材料 |
| 公共建筑、主要地标 | 较清晰的蓝色石板 | 统一城市石材、少量金属装饰 | 比住宅更规整的石工，更大的门厅与屋顶层次 |

这些颜色是分配方向，不是给每栋房子随机抽色。每条街维持主色关系；一段连续立面相邻建筑避免完全相同的屋顶轮廓、窗位与配色。墙面保持亮而不漂白，瓦片有排布、搭接、破损边缘和受光差异。屋顶有实在的檐口厚度，窗框和门洞需要凹进墙体。

磨损集中在檐口滴水线、窗台下、烟囱附近、墙基潮湿处及门阶踩踏处。主体仍是有人维护的城市，不能用满墙均匀噪点把整城弄脏。

## 4. 道路与路沿：轮廓随空间用途变化

以连续道路网络确定建筑入口和地块，再构造人行道。主路保持清楚的走向；人行道围绕路口、绿岛、雕像底座和门厅形成扩宽与退台。参考图主要体现的是**折线切角与有目的的退让**，不应全部替换成无规则曲线。

用户追加的转角要求作为全城规则：**主要步行路线遇到转向，采用短斜边切角或有控制的圆弧过渡，不保留突兀的 90° 外凸尖角。** 路沿、人行道铺装边线、绿地、树篱基座使用一致的转角轮廓，不能只把最外面一条白线画圆。切角长度建议 0.6–1.2 m，庭院小弯半径建议 0.8–1.5 m，广场更大的弧线按实际场地确定。建筑墙角和需要直角的结构节点仍按构造布置，不把整城建筑做成软圆角。玩家转弯处的碰撞边界与可见边一致；树、牌子和雕像都退到连续步行带以外。

| 模块 | 用途 | 必须实现 |
| --- | --- | --- |
| 直段 | 街道中段 | 连续顶面、立面、接缝；端点能严密连接 |
| 45° 切角 | 路口、广场、雕像岛 | 世界平面切角后再投影；转角石块合理收口 |
| 外弯 | 花坛、喷泉周边 | 顶缘、底缘同心，竖向高度不变；弧面石材不能拉花 |
| 内弯 | 绿地内凹、步道合流 | 内角有合理排水和连续铺装 |
| 入口退台 | 商店、旅店、公共建筑门口 | 人行道局部加宽，门阶完全落在平台上 |
| 坡道／降缘 | 过街、装卸和无障碍连接 | 顶面连续下降，不让人穿过垂直路沿 |
| T 形／十字收口 | 街道相交 | 去掉交叉处多余边线，避免两套路沿相互叠压 |

车行道使用蓝灰／灰紫矩形错缝铺装，人行道以较浅、不规则但尺寸有秩序的石块区别。可以按街区改变材质，而同一连通道路的铺装尺度与方向应连续。接缝积灰略深，常走区域略磨亮，破损稀疏；不要让每块石头都像独立发亮的鹅卵石。

实现路沿时，从闭合地面轮廓生成高、低边线和立面，按边朝向设置受光，给背光边投影。轮廓布尔合并后再生成可见边，避免道路交叉处出现内部“墙”。弧段以统一高度采样，斜切与弧段都要有正确碰撞和导航。材质生成只负责表面，不能替代这层结构。

## 5. 城墙：先有重量，再有石材

城门是防御体系中的开口，门塔、墙翼、墙基连续相接；每个门都有道路通过和明确的城内外两侧。普通墙段具有墙顶通道、厚实女儿墙、垛口、墙脚和角部连接，不能是竖起的一张纹理。

墙面石块大小有有限变化，主砌筑行连续；灰缝内凹，石块外缘略磨损，顶部压石受光，墙身转面变暗。墙脚有少量沉积污垢和苔藓，垛口下有细雨痕，修补处石色略有差异。门洞必须看到深度、拱券、门轴及其遮挡阴影。塔基比上部稍宽，使重心落地。

直墙、转角、塔、门、台阶共用石材尺度与光照。地面投影、门洞遮挡和玩家穿门位置须在运行场景检查；生成样件本身不能证明这些已经正确。

## 6. 树木与庭院：有秩序地多样

首批物种方向：深青绿窄冠针叶树、鲜绿扩冠阔叶树、浅银绿疏冠小乔木，另配较低的灌木与花草。每个常用物种正式库至少准备三种真正不同的轮廓／树龄变化。轻微色差可作为补充，不能用一棵树缩放和调色代替物种差异。

行道树在同一条街可以有规律地种同一种树，这是城市秩序；广场、庭院、城墙缓冲带再切换种类和密度。树距参考成熟冠幅，留出店门、传送石、过街视线和长椅使用空间。树根附近可有露土，草地保留鲜绿主体。花盆、灯柱、长椅以人和门阶为比例基准，避免为了填空塞满道具。

### 6.1 最新反馈：树不能像完美园艺模型

首轮庭院样件被用户指出树冠过满、油亮、轮廓过于完美，且与略旧建筑的画法不匹配。**该首轮树形不作为认可的美术方向**；仅改成更冷的绿色仍不够，必须改树冠结构与笔触。

树冠允许偏冠、不同长度枝条和少量透空，针叶树层级不应左右对称，也不必总有完美尖顶；小树与老树的枝干、树皮和修剪痕迹要不同。用成团的哑光笔触组织叶片，减少每片叶子的独立高光。可以有少量旧叶、断枝痕、根部露土和椅边踩踏，但整体保持有人维护的健康城市，不能把“不完美”误做成满树枯叶或荒废景观。

第三轮植被返修以现有庭院为编辑对象，以本组面包坊为画法参考，保留灯、椅、砖边和尺寸关系，重新设计树冠与枝条。第四轮直接引入用户树木截图校准偏黄的叶色与叶丛画法，保留已改出的不规则枝冠。精确提示词见 `tree-structure-revision.txt` 与 `tree-reference-revision.txt`。统一风格需要树和房屋放在同一倍率、同一底色下比较，不可仅分别看大图。

生成工具：内置 imagegen；首次生成输入保存在 `prompts.json`，各轮返修及输入文件对应关系见 `manifest.json`。最终 06、07 是 RGB 视觉审阅图，网格背景已烘焙进文件，并非透明素材；其他五张保留原始 RGBA，详见 `QA.md`。PNG 保留原始输出，不进行自动抠图、伪造透明背景或单独调色，以便明确评估生成质量。若工具输出未达到要求，在 `QA.md` 记下，不能把“提示词写了”当作“已经实现”。

正式接入前的验收：

1. **游戏倍率**：与 72 px 成人和 89 px 普通门洞对比，屋檐、灰缝、台阶、树冠暗部仍清楚；原尺寸漂亮但缩小糊成噪声不通过。
2. **共同光照**：七件并排检查，不能有左上照树、右上照房的情况；门换方向后光不翻转。
3. **四向结构**：同一建筑四向完成空间对应后，才可声明支持四向；当前四种建筑方向样件不能代替该验证。
4. **街道连续性**：门与路、坡道与人行道、弧段与直段、城门与墙体无裂缝、悬空或重复边线；逐个步行路口检查切角／弧段，以及绿地、树篱基座与路沿是否同形收口。
5. **生活和秩序**：相邻建筑不歪、入口可达，树木不挡门，细节服务功能；避免机械重复，也避免随机堆放。
6. **运行技术**：标定物理尺寸和锚点，确认透明边缘、前后遮挡、碰撞／导航；检查 PNG 的真实 alpha，而非只看预览背景。

集成顺序建议：先标定人物与基础设施尺度，再实现轮廓路沿与城墙连接；随后配置建筑四向、铺装与绿化，最后加材质磨损和小物件。先做一段包含路口、两种建筑、门墙和庭院的可行走街区验收，通过后再铺到全城。
