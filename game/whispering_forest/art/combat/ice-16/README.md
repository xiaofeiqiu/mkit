# 冰刺 · Aseprite 16 帧

一级冰：短促聚水后从地面下快速刺出。主体、碎冰和棱面高光改为霜白色，阴影仅带少量浅冷灰；去掉深蓝水柱感。用户指出动作过慢后，命中从 1.15 秒提前到 0.42 秒，全长从 3.3 秒缩短为 1.45 秒。取消先膨胀、再收缩成矮锥的旧动作。本轮先迁移冰；其他技能的 16 帧制作待继续。

## 源文件与运行时

- `ice-spear-16.aseprite`：384×384、16 个不同合成帧、4 个可编辑图层，含阶段标签及逐帧时长。水纹、冰体、高光裂纹、碎冰分别编辑。
- `author_ice.lua`：Aseprite 内的分层动画制作脚本。不是把 8 帧复制成 16 帧，也不把插值结果算作新帧。
- `../ice_spear_16.gd`、`../ice_emerge.gdshader`：完整冰体沿世界 Y 轴平移，用地面平面裁掉地下部分；各姿态的模型尺寸始终不变。
- `base/projection.json`：共享城市相机、灯光配置、固定地面原点与模型源哈希。
- `../../../assets/combat-vfx/ice-16/ice.png`：Aseprite 导出的 6144×384 RGBA 图集；`aseprite.json` 为原始导出元数据，`manifest.json` 为引擎登记和追溯记录。
- 游戏通过 `scripts/combat/vfx_frames.gd` 加载新图集；一级到十级共用这套 16 帧，保留各等级范围、数量和音效差异。

## 时序

| 帧（从 1 开始） | 起始时间 | 动作 |
| --- | --- | --- |
| 1–6 | 0 / .04 / .08 / .12 / .16 / .20 s | 水纹、细流向中心聚拢，水峰蓄势 |
| 7–9 | .24 / .30 / .36 s | 冰尖从水面以下破地、加速刺出 |
| 10–11 | .42 / .53 s | 完整冰刺、高光扫过、裂纹出现 |
| 12–16 | .65 / .79 / .94 / 1.11 / 1.29 s | 沿裂面拆成不透明碎块、移开，分块移除 |

全长 1.45 秒。第 10 帧起点 0.42 秒同时触发伤害、冻结与一级用户录音 `冰1.wav` 的现有导出。保留原命中录音及播放速度，尾音能在动画结束前播放完整。`ice_motion.gd` 统一保存动作时间轴，模型导出、Aseprite 和游戏读取同一份时长。游戏按 Aseprite 毫秒时长逐张播放；快速刺出阶段不混合两张不同高度的冰尖，避免双影。

地面原点固定在 (192, 297.818)，统一输出密度与运行时 0.5 倍率；不根据帧内容重新居中。冰体及碎片保持实心不透明，游戏不再施加全局透明淡出。后半程把固定大小的冰体拆成不规则碎块，逐块移开和移除；保留透明背景和轮廓抗锯齿。目标移动后法术仍留在原地；多重冰刺各自拥有完整时间轴。

## 重建与检查

在项目根目录执行 `python3 game/whispering_forest/tools/build_ice_16.py`。依次运行共享 3D 渲染、Aseprite 脚本、Aseprite 原生图集导出、引擎登记和动作板/GIF 输出。可通过 `GODOT` 与 `ASEPRITE` 指定程序路径；默认使用本机已有安装。

图集更新后让 Godot 导入图片，再执行 `python3 game/whispering_forest/tools/verify_combat.py`。该检查覆盖 16 个不同帧、真实透明、固定原点、源哈希、逐帧时长、峰值不回缩、120/30/8 次更新下的命中同步、取消和多重释放。技术检查通过不替代用户的美术反馈。

动作预览位于 `../../../preview/ice-16.gif`，16 帧动作板为 `../../../preview/ice-16-frames.png`。实机有声录像为 `../../../preview/ice-16-solid-gameplay.mp4`，事件记录为 `../../../preview/ice-16-events.json`。



## 本轮不透明度验证

- 战斗检查通过：冰在收尾阶段的运行时不透明度仍为 1，动画完成时移除；命中时长、冻结、音效和多重释放保持原值。
- GPU 检查通过：在 0.42 / 0.65 / 0.94 / 1.29 秒抽样，共 1034 个冰体和碎块内部像素保持不透明。采样排除抗锯齿边缘和碎块之间的空隙。
- 检查命令：Godot 使用 `--rendering-method gl_compatibility --script res://game/whispering_forest/tools/check_spell_blending.gd`。日志为 `preview/ice-16-opacity.log`。
