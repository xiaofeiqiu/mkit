# Impact audio sources

Kenney Impact Sounds 1.0 and RPG Audio 1.0, CC0. Original license files are retained in each directory.

- https://kenney.nl/assets/impact-sounds
- https://kenney.nl/assets/rpg-audio

Downloaded 2026-09-06. These are source foley samples. Runtime mixes live in `assets/impact-audio`, generated by `tools/make_impact_audio.py`: contact foley, filtered textures, original low-frequency/elemental layers, alternate takes, stereo tails, DC removal and headroom. City music and the separate elemental skill library are untouched.
