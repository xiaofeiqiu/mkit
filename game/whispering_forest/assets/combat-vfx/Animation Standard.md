# 魔法动画：16 帧升级与固定原点

2026-09-06 最新修订：用户要求所有技能升级到 16 帧，用 Aseprite 制作，先做冰。目前冰已使用新制 16 帧，火、风、陨石、终极保留原有 8 帧，等待后续迁移。运行时按 `clips.json` 中每个技能的实际帧数读取，不能把旧帧重复两次冒充升级。冰的源文件、时序和重建方法见 [冰刺 Aseprite 制作记录](../../art/combat/ice-16/README.md)。

## 制作与位置规则

1. 有体积的冰柱、陨石和龙卷使用可编辑模型及共享 `art/city/render_stage.gd`。固定 2:1 正交相机、左上灯光、世界比例、384×384 画布；每帧只改变模型动作。
2. 冰与风的地面原点来自模型 `(0,0,0)` 的投影，当前输出为 `(192,297.818)`；陨石以石体中心为旋转原点 `(192,192)`。精灵使用完整画布，不按可见内容逐帧居中、填满或拉伸。
3. 若将来裁切透明边距，必须同时记录原裁切区域和 `原点 − 裁切偏移`，播放时还原。不能从每帧最下方像素猜测地面位置；冰屑、拖尾、发光边缘均不参与锚点定义。
4. 火爆术是以空中中心向四周膨胀的爆炸。当前选用两个原创图集中的 8 个有效姿态，以元数据对齐爆炸中心，保留每帧原有大小。没有修改 PNG 像素或拿截图当素材。
5. 法术的世界坐标和动画画布原点分别管理。固定法术在释放时保存落点值，伤害和视觉共用快照；之后原目标移动、击退、死亡或被移除均不改变它。风拥有独立运动轨迹。

## 当前各技能的动作节奏

帧数与游戏渲染帧率不同。冰使用 16 个独立合成帧及 Aseprite 逐帧时长，完整播放 1.45 秒；0.24 秒聚水后破地，0.42 秒达到峰顶，随后以不透明碎块裂开、移出和移除。其余待迁移动画仍用原时序和相邻帧混合。

冰逐帧播放，快速刺出时避免混合两张不同高度的冰尖；其他技能的相邻帧在 `clip_blend.gdshader` 中按预乘 alpha 插值后一次绘制，避免直接叠加两张半透明精灵使石体在中间姿态变成 75% 不透明。真实 GPU 检查 `tools/check_spell_blending.gd` 已验证旋转中石体保持实体不透明，结束时按规定透明度淡出。

| 法术 | 帧与阶段 | 声音与事件 |
|---|---|---|
| 火爆术 | 小球 → 膨胀 → 爆开 → 裂开 → 零散火花；一级 8 帧，以完整音效的实际长度约 1.13 秒结束并渐隐；2–10 级沿用 2.4 秒 | 一级使用参考指导的原创短爆音，从施法释放开始，约 0.096 秒产生伤害，尾音结束时动画消失；其他等级保留分阶段声音 |
| 冰冻术 | 16 帧：1–6 聚水蓄势；7–9 破地刺出；10–11 峰顶与裂纹；12–16 实心碎冰移出、移除；共 1.45 秒，实心霜白色主体，取消回缩和透明淡出 | 第 10 帧起点 0.42 秒同时触发伤害、冻结和一次命中音效；一级保留用户提供的冰录音；聚水和上升阶段无提前伤害或命中音 |
| 龙卷 | 宽窄交错、末端渐尖的弧形白色风带，保留透空层次；8 帧、8 fps、一秒循环；直行、转弯、绕圈及反射独立于图集播放；结束后 0.9 秒渐隐 | 初生声、持续风声、反射声；实际命中使用用户的一级/十级录音，最多两条命中尾音重叠；暂停和离场会停止/暂停风声 |
| 土系陨石 | 6 个不同旧石模型，每个模型 8 个真实旋转姿态；0.95 秒加速下坠，命中后留存 1 秒 | 飞行渐强风声；命中时低沉撞击、碎石；白灰颗粒尾巴沿历史轨迹消散 |
| 火陨终极 | 复用 8 姿态的陨石和 8 帧爆炸；独立结印/下降/爆炸时序 | 结印 0 秒、下坠 0.25 秒、撞击 1.3 秒三个独立声音 |

一级与十级保留范围、数量和声音强度差别；不通过给高级魔法增加帧数来改变动作格式。

多重施法现在采用统一释放队列：默认在 0.8 秒内均匀释放完所有元素，5 枚在 `0 / 0.2 / 0.4 / 0.6 / 0.8` 秒出现。每枚从实际释放时才创建动画，其独立寿命不计入释放窗口；冰在自己的 0.42 秒峰顶触发声音，陨石下落自己的 0.95 秒后撞击，一级火焰保留自己的 1.13 秒完整音画。详见 [多重元素依次释放](Multi%20Release.md)，实机预览为 `preview/volley-v7.mp4`。

## 防止同类回归

`tools/bake_solid_spells.gd` 在导出时检查共享投影、地面原点和每格透明边缘。`tools/spell_asset_checks.gd` 已接入 `tools/verify_combat.py` 与 `tools/verify_feel.py`：

- 检查各主动画登记帧数（冰 16，其余当前 8）、图集尺寸和真实 RGBA；冰还核对 Aseprite 原始元数据、16 张不同合成帧和时长。
- 按已知相机公式独立计算原点，与元数据核对；检查每格非空且没有顶到边缘。
- 核对模型、导出器、共享相机配置和导出 PNG 哈希，拒绝修改后忘记重新导出的资产。
- 游戏回归让原目标离开冰区、另一只怪进入冰区，验证冰的屏幕/世界位置和命中判定都留在原来的位置。
- `tools/spell_alignment_board.gd` 输出八帧十字原点对照图；连续实机录像检查相邻帧衔接、材质变化、遮挡和音效。锚点正确仍不能自动保证动作、美术和声音达到商业品质，需要实际审阅。
