# 一级火焰 · 完整爆音与动画同终点

用户指定 `cgefc15.wav` 为一级火焰声音参考，并要求音效结束时动画也结束。参考长 1.130703 秒，开头的能量强、低频为主，随后明显衰减。本版使用原创滤波噪声和压力共振重新合成短促爆音，以这些时长、频段及衰减特点为指导；没有直接使用或混入参考音频。

- 运行时声音：`fire-level-1.wav`，48 kHz、双声道、16-bit PCM，54274 个采样帧，1.130708 秒。
- 生成脚本：`tools/make_fire_audio_v5.py`；可编辑压力、气流、起爆和少量立体声空气层：`art/audio/fire-v5/`。
- 来源、参考哈希、输出哈希和音量测量：`manifest.json`。参考文件保持原样。
- `scripts/combat/fire_cue.gd` 是一级火焰的统一时间定义。直接读取导入声音的真实长度，供声音播放、8 帧动作和视觉移除使用；播放音高固定为 1，避免随机变速造成收尾偏移。
- 8 个姿态位于音频时长的 `[0, .035, .085, .16, .30, .47, .69, 1]`，约 0.096 秒产生爆炸伤害；后段随尾音渐隐。角色原有施法准备发生在本效果开始前。
- 每个火爆的整段声音从它实际释放时开始，只播放一次。多重效果在 0.8 秒窗口内依次释放，各自保留 1.13 秒音画长度。一级 AOE 伤害不叠旧的点火声或通用火焰撞击录音；普通火属性普攻仍保留自己的受击音效。
- 静音时动画仍按相同时间完成；暂停会同时暂停音频及战斗推进；离场/重置同时停止声音、移除动画并清除待执行伤害。

本次只调整一级火焰声音和时间，保留原有 8 张火焰素材。其他等级仍用原分阶段声音及时长；原点、范围和等级数值沿用既有规则。

战斗回归 `tools/verify_combat.py` 已覆盖音频实际时长与动画寿命一致、固定音高、8 帧、逐渐淡出、终点前后状态、静音行为、旧声音不叠加、普通火弹反馈及重置停止。实机脚本 `--wf-combat-review --wf-fire-review` 录制三次完整一级施法；`preview/fire-v5-events.json` 记录每次声音与画面末帧，30 fps 下按下一个画面帧移除。技术检查不能代替对最终音色的审听。
