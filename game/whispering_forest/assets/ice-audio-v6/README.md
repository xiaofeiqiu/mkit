# 一级冰魔法 · 峰顶命中音效

**历史版本，已停用此音频。** 用户报告声音错误后发现本版所用 `cgefc15.wav` 与火焰参考相同。当前一级冰改用 `assets/ice-audio-v8/` 的独立 `冰1.wav`，峰顶命中时序保留。

用户本轮明确指定 `cgefc15.wav` 为一级冰魔法音效，并要求冰柱长到最高才击中敌人和播放声音。本目录采用这段用户提供的录音；不是原创合成，也不标记为 CC0 素材。原文件保持不变，工作副本保存在 `art/audio/ice-v6/user-supplied/ice-level-1-source.wav`。

`tools/prepare_ice_hit.py` 将其转为 48 kHz、双声道、16-bit PCM，音量降低 2 dB，末尾 12 ms 淡出防截断杂音。原音高和节奏保留。`manifest.json` 记录来源、处理和文件哈希。

冰魔法的事件顺序为：白印 → 安静上升 → 最高冰柱与一次伤害/冻结/音效 → 回缩冰锥 → 淡出。8 帧、固定落点和总长 3.3 秒沿用现有动画；最高姿态是第 5 张图，1.15 秒开始。`ICE_HIT` 直接引用 `ICE_PEAK`；回归另从图集的模型高度和帧时间推导最高姿态，防止时间常量与实际素材脱节。

一级在峰顶播放 `hit-level-1.wav`；其他等级在同一峰顶事件播放已有对应级别的冰命中声音。旧的白印、上升、回缩录音不再排队播放，通用 water 受击声音不叠加。多重冰现在在 0.8 秒释放窗口内依次出现，每根柱在自己的峰顶播放一次声音；重叠区域的伤害仍是每目标每次施法一次。目标离开固定冰区可以避开伤害，新进入者会在峰顶被命中。

检查：`tools/verify_combat.py` 覆盖 120/30/8 次更新下的实际扣血、冻结、当前最高姿态与音效事件；最高前不命中、不发声；最高停留阶段不重复；到峰顶前取消会清理待执行伤害和声音。实机入口 `--wf-combat-review --wf-ice-review` 在隔离状态下演示两次一级施法，不改玩家存档。

实机录像 `preview/ice-v6.mp4`；逐次命中与声音记录 `preview/ice-v6-events.json`；30 fps 录制下，1.15 秒事件在紧接的画面更新中出现。
