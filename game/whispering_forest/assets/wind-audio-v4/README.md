# 龙卷命中声音与八帧外观 · v4

用户提供的 `风1.wav` 是一级命中，`风2.wav` 是十级命中。本版直接采用这两段命中录音，不把它们当作施法或持续风声。

| 文件 | 用途 | 处理 |
|---|---|---|
| `hit-small.wav` | 1–5 级命中，来自一级录音 | 原音色、原节奏，降低 2 dB |
| `hit-full.wav` | 6–10 级命中，来自十级录音 | 原音色、原节奏，降低 1 dB |

统一为 48 kHz、双声道、16-bit PCM；原始单声道等量送到左右声道，不添加虚假的立体声宽度。仅末尾 12 ms 淡出防止截断杂音。源录音原样保存在 `art/audio/wind-v4/user-supplied/`；`manifest.json` 记录源与输出哈希。来源标记为用户提供，不能与项目的原创合成或 Kenney CC0 音源混同。

`tools/prepare_wind_hits.py` 可从已保存的源文件重新导出。普通初生、持续风声、撞墙声仍由 `spell-audio-v2` 提供。只有龙卷实际造成伤害才播放本目录的命中音效；闪避、空放、只撞墙均不触发。使用施法时等级，避免在飞行期间升级后换错录音。全场共享 0.22 秒命中音频间隔、最多两条命中尾音同时播放；伤害仍保持独立的每敌人 0.30 秒间隔。

龙卷模型改为宽窄交错、末端渐尖的弧形风带，使用白色亮边、冷灰背面和底部小团风沫表现层次，保留带间空隙。8 张关键帧以 8 fps 循环一秒，插值只负责过渡，不额外生成素材帧；移动轨迹、等级尺寸及结束后的 0.9 秒渐隐独立于循环。

相关检查：`tools/verify_combat.py` 验证八帧、固定原点、透明边界、源文件哈希，以及真实命中等级选择、空放/墙碰不误播、群体命中去重和最多两声音重叠。`tools/wind_board.gd` 输出八帧原点图；`--wf-combat-review --wf-wind-review` 在隔离状态下录制一级与十级，使用实际碰撞与音频事件，不改玩家存档。

预览：`preview/wind-v4.mp4`；逐帧图：`preview/wind-eight-v4.png`；事件记录：`preview/wind-v4-events.json`。技术验证不能代替用户对美术和音色的最终审阅。
